### Key Features

- User-based task management
- Add, update, and delete tasks
- Mark tasks as complete or pending
- Priority levels (Low, Medium, High, Critical)
- Due date management
- Task tags
- Subtask management
- Search functionality
- Task filtering
- Sorting options
- Statistics dashboard
- Overdue task detection
- Upcoming task reminders
- JSON-based persistent storage
- Export task reports
- Command-line interface

### Technologies

- Datetime Module

# Installation

## Clone the Repository

```bash
git clone https://github.com/mahnoor-yasir/DecodeLabs-Internship.git
```

---

## Navigate to the Repository

```bash
cd DecodeLabs-Internship
```

---

## Open Any Project

Each project is independent and can be executed separately.

Examples:

```bash
cd "Project 1 To-Do List"
```

```bash
cd "Project 2 Expense Tracker"
```

```bash
cd "Project 3 Random Password Generator"
```

```bash
cd "Project 4 General Knowledge Quiz"
```

---

## Run a Project

Run the required Python file.

Example:

```bash
python main.py
```

or

```bash
python app.py
```

or

```bash
python to_do_list.py
```

or

```bash
python random_password_generator.py
```
