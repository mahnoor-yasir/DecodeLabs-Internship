# KnowledgeHub

An enterprise-style General Knowledge Quiz application developed in Python using Tkinter and SQLite. The application provides category-based quizzes, multiple difficulty levels, score tracking, leaderboard management, question management, analytics, and report export through a modern desktop interface.

- Interactive General Knowledge Quiz
